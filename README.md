🔹 **Memory & PLD Educational Lab Simulator**

In this project, I have developed a **web-based Digital Electronics laboratory** to help students learn and understand **Memory and Programmable Logic Devices (PLDs)** in a simple and interactive way.

The website allows users to simulate:

🔸 RAM memory read and write operations
🔸 Memory address decoding
🔸 PLA Boolean logic and truth tables
🔸 PAL Boolean logic and truth tables
🔸 Digital circuit simulations
🔸 Fault detection and fault simulation
🔸 Digital Electronics experiments
🔸 Automated test cases
🔸 Experiment report generation

The main goal of this project is to make **Digital Electronics learning more practical and interactive**. Instead of only studying the theory, students can perform simulations, enter inputs, observe results, test faults, and understand how the circuits work.

This project was developed as part of my **ECE / Digital Electronics learning and project work**.
